# 慕喜乐夫妻营 · 评估系统微信云托管极速部署指南

本目录包含了一套专为**微信云托管（WeChat CloudBase / Cloud Run）**打造的轻量生产就绪代码，包含：
- `index.html`：客户答题端（纯净零默认值、完全隔离报告与后台、独立作答加密提交）；
- `admin.html`：咨询师工作台（密码保护、双轨雷达图、四象限全景诊断、定制咨询话术、21天夫妻营促单武器库）；
- `server.js` & `Dockerfile`：Node.js 极简后端服务，支持数据存储与调取。

---

## 一、微信云托管部署 3 步走（耗时约 5 分钟）

### 第一步：登录微信云托管控制台
1. 访问微信云托管官网：[https://cloud.weixin.qq.com/](https://cloud.weixin.qq.com/)
2. 使用企业微信公众号/小程序管理员账号扫码登录。
3. 新建或选择一个环境（如 `muxile-prod`）。

### 第二步：创建服务并部署
1. 点击左侧菜单【服务管理】 -> 【新建服务】，输入服务名称：`marriage-survey`。
2. 在【版本管理】中点击【部署发布】：
   - **部署方式**：选择【本地代码上传】（将当前 `慕喜乐夫妻营测评系统/` 整个文件夹压缩为 `.zip` 包上传）；
   - 或者选择【代码库关联】（推送到 GitHub / Gitee 后直接点关联）。
3. 容器端口设置为：`80`。
4. 点击【确定发布】，系统将自动进行 Docker 镜像构建并上线。

### 第三步：获取与配置公网访问链接
1. 发布完成后，进入【服务设置】 -> 开启【公网访问】；
2. 系统会自动免费分配一个类似如下的默认域名：
   `https://marriage-survey-xxxxxx.service.tcloudbase.com`
3. 也支持在【域名管理】中绑定公司自有的独立域名（如 `eval.muxile.com`）。

## 二、业务流程链接配置与自动化发货

在微店、小红书或小鹅通等平台设置自动发货规则：

1. **自动发货给买家的答卷链接**：
   - 基础链接：`https://你的域名/index.html?order={ORDER_ID}`
   - 示例：`https://eval.muxile.com/index.html?order=MSL20260901`
   - 买家打开后可自由选择“妻子卷”或“丈夫卷”，答完后复制给伴侣作答。

2. **咨询师内部专属后台链接（请勿发给买家）**：
   - 链接：`https://你的域名/admin.html`
   - 默认访问密码：`mxl2026`（可在 `admin.html` 源码中自行修改）。
   - 咨询师在微信预约解读前，输入客户的订单号，即可瞬间调出雷达图、四象限诊断与对应促单话术。
